Everything below will eventually moved into a single 'frame' component which will change it's content depending on user actions.

  • account-select will be the component to toggle between viewing an entire portfolio or individual account details. This can be made up of smaller button components (maybe they can be reused elsewhere?)
  • account-overview will display current value of an account. This includes balance and cash balance. If a user selects an individual account, it will show detailed information about that account rather than total portfolio value.
  • account-details is a component that displays all assets currently held by the selected account. If user has selected 'all' in account-select, it will show all accounts separated by headers. Assets must be separated by account since they will have different avg. bought price.
